# English to Bengali Console Translator

A simple Java-based console application that translates common English phrases into Bengali. 
Users can also add custom translations for learning purposes.

## Features
- View available words
- Translate English to Bengali
- Add custom words
- Offline usage
- Console-based interface

## How to Run
1. Compile: javac translatemanual.java
2. Run: java translatemanual
